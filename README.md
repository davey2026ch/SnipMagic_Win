# 截图工具（Windows 绿色版）

一款基于 **C/C++ Win32 API + GDI+** 的 Windows 截图标注工具，免安装，双击即可使用。

## 功能

- **区域截图**：`Ctrl+Shift+R`（可在设置中修改），全屏变暗框选，实时显示宽×高
- **多页签**：每次截图生成一个页签（P1、P2…），可切换 / 右键关闭 / 保存 / 全部保存；页签宽度为原来的 50%
- **页签对比**：右键页签 →「与当前页签对比」，在当前页签右侧分栏展示目标页签；「同步滚动」开关默认开启，右侧另有「退出对比」
- **提取内容 / 魔法消除**：顶栏入口；API Key 在设置中配置（MinerU / 火山引擎）
- **标注工具**：选择、笔刷、查看、文字、箭头、直线、画笔、矩形 / 圆角矩形 / 毫圆（空心与实心）、序号
- **马赛克**：框选后一键打码，密度可设置
- **移花接木**：`Ctrl+C` / `Ctrl+V` 在页签间或粘贴到外部软件
- **同色覆盖**：实心矩形 + 吸管取色，用于抹除局部元素
- **颜色面板**：色相圆盘 + 明度 / R / G / B / 透明度 + HEX + 全屏吸管（10× 放大镜）
- **撤销重做**：`Ctrl+Z` / `Ctrl+Y`，最多 100 步
- **缩放**：`Ctrl+滚轮`，10%–800%，接近 100% 自动吸附
- **多显示器 / 高分屏**：Per-Monitor V2 DPI 感知
- **配置文件**：程序同目录 `截图工具.ini`，启动时自动创建

## 快捷键

| 功能 | 快捷键 |
|------|--------|
| 区域截图 | Ctrl+Shift+R |
| 复制选区 | Ctrl+C |
| 粘贴 | Ctrl+V |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y / Ctrl+Shift+Z |
| 删除选中 | Delete |
| 取消 | Esc |
| 锁定方向 | Shift |
| 保存当前页签 | Ctrl+S |

## 构建

环境要求：

- Windows 10/11 x64
- Visual Studio 2022 Build Tools（含 MSVC 与 CMake）

```bat
build.bat
```

产物：`dist\截图工具.exe`

## 打包绿色版

```bat
package.bat
```

生成目录：`截图工具-绿色版\`，内含单个 exe，拷贝到任意位置双击运行。

## 目录结构

```
src/           源码（Win32 + GDI+）
app.manifest   DPI / ComCtl 清单
CMakeLists.txt CMake 工程
build.bat      一键编译
package.bat    打包绿色版
dist/          编译输出
```

## 技术说明

- 语言：C++17
- UI：纯 Win32 窗口 + GDI+ 自绘
- 图像：GDI+ Bitmap
- 配置：Win32 INI API
- 单实例：命名互斥体，再次启动会激活已有窗口
- 关闭：有未保存页签时询问是否保存；选「是」后取消路径/格式选择则不退出并重新询问
