# 截图工具（Windows 绿色版）

一款基于 **C/C++ Win32 API + GDI+** 的 Windows 截图标注工具，免安装，双击即可使用。

## 核心特点

1. **支持区域截图、长截图**，一张图片占据一个 sheet 页签。长截图针对微信聊天等**大片空白界面**做了防重复对齐，整块内容不再被重复拼接。
2. **两图对比**：显示页签 A 的图像，再右键点击页签 B，实现 AB 两图左右并列显示，默认开启同步滚动。
3. **框选图片中某个局部区域后**：
   1. **精确提取**：框选后点「提取内容」，只识别框内内容（不框选则识别整图）；
   2. **抠起移动**：在框选区内按下鼠标拖动，选区画面整体搬走，**原位置自动填白并烙进底图**（非浮层，保存后依然是白的），搬走的内容可继续拖动摆放，`Delete` 丢弃、`Ctrl+Z` 撤销；
   3. **马赛克**：点击马赛克按钮，对选中区域打码；
   4. **移花接木**：使用 `Ctrl+C`、`Ctrl+V` 复制、粘贴。可以粘贴到当前图片中、粘贴到其他页签的图片中；
   5. **粘贴到外部**：把框选区域复制到剪贴板后，粘贴到文档、微信等外部软件；
   6. **魔法消除**：用「擦除刷」刷出（或框选）要去掉的内容，点按钮交给 AI 重建背景 —— 文字、水印、Logo、杂物都能抹掉，且保留背景纹理。细长选区等特殊尺寸会自动适配接口要求，无需手动调整。火山 API Key 申请地址（费用超低）：<https://console.volcengine.com/imp/ai-mediakit/settings>。
4. **同色覆盖（抹除局部元素）**：先设置或吸取颜色（全局吸管，动态显示颜色值），再使用实心矩形去遮盖目标区域。取色时颜色窗口会自动隐藏，拾取完成后自动带出所选颜色。
5. **支持 OCR 提取内容，导出 Markdown、Word、Excel**：
   1. 绝大部分情况下，只能解析出文字 + 表格；
   2. 部分图文混排的图片，可以解析出文字 + 图片（抠图）；
   3. **超长截图自动切片识别**：微信长截图等超高图片会自动切成多条、按序上传、按序合并（接缝去重），避免云端压缩整图导致文字丢失、顺序错乱；
   4. 提取完成后，自动写入剪贴板，方便直接粘贴；
   5. 后台对接免费的 MinerU 接口，Token 申请地址：<https://mineru.net/apiManage/token>；
   6. 配置文件路径：当前程序目录下的截图工具.ini文件
6. **支持常规编辑**：文字、画笔、箭头、直线、边框、序号、撤销、重做等。**左侧工具栏大部分图标，默认单次用完即退，双击锁定复用**：
   1. **单击工具按钮（默认）**：拖拽画出组件后自动回到选择状态，组件带 8 个控制点，可拖动位置、调整大小；
   2. **双击工具按钮锁定**：图标右下角出现小锁标记，可连续添加同类组件（再双击解锁）；文字的四个角点支持整体放大缩小（字号同步变化）；
   3. 所有弹窗（文字、颜色、设置、提取、消除）都显示在截图工具所在的显示器上，多屏不再乱跳。
7. **支持自动更新**：启动时静默检查云端新版本，发现后弹窗询问，同意才下载安装并自动重启。设置界面亦可手动更新。

## 快捷键

| 功能 | 快捷键 |
|------|--------|
| 区域截图 | Ctrl+Shift+R |
| 长截图 | Ctrl+Shift+E |
| 完成长截图 | Enter（会话中） |
| 取消长截图 | Esc（会话中） |
| 复制选区 | Ctrl+C |
| 粘贴 | Ctrl+V |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y / Ctrl+Shift+Z |
| 删除选中 | Delete |
| 取消 | Esc |
| 锁定方向 | Shift |
| 保存当前页签 | Ctrl+S |

## 构建

环境要求：

- Windows 10/11 x64
- Visual Studio 2022 Build Tools（含 MSVC 与 CMake）

```bat
build.bat
```

产物：`dist\截图工具.exe`

## 打包绿色版

```bat
package.bat
```

生成目录：`截图工具-绿色版\`，内含单个 exe，拷贝到任意位置双击运行。

## 目录结构

```
src/           源码（Win32 + GDI+）
  longstitch.* 长截图拼接算法
  longcapture.*长截图会话（抓帧 + 控制条）
app.manifest   DPI / ComCtl 清单
CMakeLists.txt CMake 工程
build.bat      一键编译
package.bat    打包绿色版
dist/          编译输出
```

## 技术说明

- 语言：C++17
- UI：纯 Win32 窗口 + GDI+ 自绘
- 图像：GDI+ Bitmap
- 配置：Win32 INI API
- 单实例：命名互斥体，再次启动会激活已有窗口
- 关闭：有未保存页签时询问是否保存；选「是」后取消路径/格式选择则不退出并重新询问
