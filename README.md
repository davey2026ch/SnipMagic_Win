# 截图大师 SnipMagic（Windows 绿色版）

一款基于 **C/C++ Win32 API + GDI+** 的 Windows 截图标注工具，免安装，双击即可使用。

## 主要特色

1. **支持区域截图、长截图**，一张图片占据一个 sheet 页签。长截图过程中，需要缓慢滚动页面。
2. **两图对比**：显示页签 A 的图像，再右键点击页签 B，实现 AB 两图左右并列显示，默认开启同步滚动。
3. **框选图片中某个局部区域后**：
   1. 精确提取：框选区域后，点「提取内容」，只 OCR 识别框内内容（不框选则识别整图）；
   2. 抠起移动：框选区域后，按下鼠标拖动，选区画面能整体搬走，类似于剪切；
   3. 马赛克：点击马赛克按钮，对选中区域打码；
   4. 移花接木：框选区域后，使用 Ctrl+C、Ctrl+V 复制、粘贴。可以粘贴到当前图片中、粘贴到其他页签的图片中；
   5. 粘贴到外部：框选区域后，使用 Ctrl+C、Ctrl+V 复制、粘贴文档、微信等外部软件（此时自动添加边框）；
   6. 魔法消除：框选区域后，点「魔法消除」，消除内容，AI 重建背景。
4. **魔法消除**：框选区域 或 用「笔刷」刷出要去掉的内容，点「魔法消除」，消除内容，AI 重建背景（文字、水印、Logo、杂物都能抹掉，且恢复背景纹理）。火山 API Key 申请地址（费用超低）：https://console.volcengine.com/imp/ai-mediakit/settings
5. **同色覆盖**：先设置或吸取屏幕颜色，再使用实心矩形去遮盖目标区域。
6. **抹除局部元素的两种方法**：
   1. 如果背景干净，优先推荐“同色覆盖”的方法；
   2. 如果背景复杂，优先推荐“魔法消除”的方法，AI 自动重建背景。
7. **提取内容**：
   1. 框选区域后，精确提取此区域的值；如果不框选，则提取整张图的值；
   2. 提取完成后，自动写入剪贴板，方便直接粘贴；
   3. 绝大部分情况下，能解析出文字、表格；部分图文混排的图片，还可以解析出图片（类似于抠图）。对于复杂图片，建议导出后查看；
   4. 支持导出为 Markdown、Excel、Word，导出时自动解析转换表格、添加图片；
   5. 后台对接免费的 MinerU 接口，需要每 3 个月更换一次，Token 申请地址：https://mineru.net/apiManage/token
8. **支持常规编辑**：文字、笔刷、画笔、箭头、直线、边框、序号、撤销、重做等。
9. **左侧工具栏图标**：
   1. 默认启用框选按钮；
   2. 大部分图标：单击操作，用完即退；双击可锁定图标，不断复用（类似于 Office 软件中批量格式刷），再次单击取消锁定；
   3. 生成的组件，可以移动位置、调整大小。对于文字组件，可以拖动自由缩放文字大小、调整跨行显示效果。
10. **支持多屏操作**：适配超清屏，多屏不乱跳。
11. **支持联网更新**：启动时静默检查新版本，发现后弹窗提醒，用户同意后自动下载和重启。在设置界面亦可手动检查更新。

## 快捷键

| 功能 | 快捷键 |
|------|--------|
| 区域截图 | Ctrl+Shift+R |
| 长截图 | Ctrl+Shift+E |
| 完成长截图 | Enter（会话中） |
| 取消长截图 | Esc（会话中） |
| 复制选区 | Ctrl+C |
| 粘贴 | Ctrl+V |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y / Ctrl+Shift+Z |
| 删除选中 | Delete |
| 取消 | Esc |
| 锁定方向 | Shift |
| 保存当前页签 | Ctrl+S |

## 构建

环境要求：

- Windows 10/11 x64
- Visual Studio 2022 Build Tools（含 MSVC 与 CMake）

```bat
build.bat
```

产物：`dist\SnipMagic.exe`

## 打包绿色版

```bat
package.bat
```

生成目录：`截图大师SnipMagic-绿色版\`，内含 SnipMagic.exe（英文名）与 截图大师SnipMagic.exe（中文名）两个副本，拷贝到任意位置双击运行。

## 目录结构

```
src/           源码（Win32 + GDI+）
  longstitch.* 长截图拼接算法
  longcapture.*长截图会话（抓帧 + 控制条）
app.manifest   DPI / ComCtl 清单
CMakeLists.txt CMake 工程
build.bat      一键编译
package.bat    打包绿色版
dist/          编译输出
```

## 技术说明

- 语言：C++17
- UI：纯 Win32 窗口 + GDI+ 自绘
- 图像：GDI+ Bitmap
- 配置：Win32 INI API
- 单实例：命名互斥体，再次启动会激活已有窗口
- 关闭：有未保存页签时询问是否保存；选「是」后取消路径/格式选择则不退出并重新询问
